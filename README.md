# web-application-security-lab.
A practical web application security lab covering OWASP Top 10, vulnerability analysis, secure coding, testing and remediation.
Web Application Security Lab

Project Overview

This project focuses on understanding web application security, identifying common vulnerabilities, analyzing security risks, and recommending appropriate remediation methods.

Objectives

- Understand HTTP requests and responses.
- Learn cookies, sessions, authentication and authorization.
- Study OWASP Top 10 vulnerabilities.
- Practice secure coding techniques.
- Perform security testing in a controlled sandbox.
- Document findings and remediation recommendations.

OWASP Top 10

1. Broken Access Control
2. Cryptographic Failures
3. Injection
4. Insecure Design
5. Security Misconfiguration
6. Vulnerable and Outdated Components
7. Identification and Authentication Failures
8. Software and Data Integrity Failures
9. Security Logging and Monitoring Failures
10. Server-Side Request Forgery (SSRF)

Practical Lab

The practical activities will follow:

1. Identify
2. Analyze
3. Test in a safe sandbox
4. Fix
5. Document
